# Kailas Nadh — Portfolio

Modern single-page portfolio built with React, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Customize

Edit **`src/data/profile.js`** for your bio, skills, projects, email, and social links.

Optional headshot: add e.g. **`public/photo.jpg`** and set **`photoUrl`** in `src/data/profile.js`. Do not use ID documents (PAN, passport scans) as site assets.

## Build for production

```bash
npm run build
npm run preview
```

Deploy the `dist` folder to Netlify, Vercel, GitHub Pages, or any static host.

## Privacy

Government ID numbers from source documents are **not** included on the site. Keep passport, PAN, and full street address private.
